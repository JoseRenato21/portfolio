# Portfólio

Site pessoal de José Renato Araújo Pereira, em uma única página HTML, sem dependências e sem etapa de build.

Publicado em https://joserenato21.github.io/portfolio/

## Conteúdo

- Sobre, experiência profissional e iniciação científica
- Infraestrutura e redes, segurança da informação, dados e desenvolvimento de software
- Mesa digitalizadora e caderno digital
- Contato

## Tecnologia

HTML e CSS em um arquivo (`index.html`), com tema claro e escuro conforme o sistema, diagramas em SVG embutido e navegação por âncoras com rolagem suave. Funciona em celular e computador.

## Executar localmente

```bash
open index.html
```
